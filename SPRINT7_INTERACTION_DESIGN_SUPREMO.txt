🎨 SEIS MECÁNICAS DE INTERACCIÓN DISRUPTIVA IMPLEMENTADAS:

1️⃣  EFECTO GRAVEDAD CERO (Transiciones Fluidas Cinematográficas)
   ├─ Pregunta saliente: scale(0.97) + translateY(-40px) + blur(8px) contexto
   ├─ Transición: cubic-bezier(0.25, 0.46, 0.45, 0.94) — 300ms desaceleración física
   ├─ Pregunta entrante: slideUp animation desde translateY(60px) → 0
   ├─ Contexto: backdropFilter: blur(8px), opacity: 0.3 (±1 pregunta visible, desenfocada)
   ├─ Efecto cinematográfico: usuario en espacio 3D donde presente = nítido, pasado/futuro = etéreo
   └─ CSS: animation: slideUp 400ms cubic-bezier(0.34, 1.56, 0.64, 1) forwards

2️⃣  INTERACCIÓN HÁPTICA DIGITAL (Microvibración Inteligente)
   ├─ Respuesta afirmativa: navigator.vibrate(50) — pulso limpio, 50ms
   ├─ Alerta/riesgo: navigator.vibrate([30, 20, 30]) — doble pulso alternado
   ├─ Pausa larga (>15s): navigator.vibrate([10, 5, 10, 5, 10]) — patrón de alerta
   ├─ Botones neumórficos: inset-shadow dual (luz + sombra interna)
   ├─ Hover: inset-shadow reducido simulando hundimiento presión dinámica
   ├─ Active: translateY(4px) simulando click físico de trackpad Macbook
   └─ Transición: 150ms cubic-bezier para flujo natural

3️⃣  DISEÑO VISUAL PREMIUM DARK/LIGHT EDITORIAL
   ├─ Tipografía preguntas: Chronicle Display (Serif elegante), 32px, 700 weight
   ├─ Tipografía opciones: Inter (Sans-serif geométrica), 16px, 500 weight
   ├─ Fondos adaptativos por dimensión:
   │  ├─ D1 Tiempo (Hogar): linear-gradient lino/arena #f5ede0 → #f0e6d8
   │  ├─ D2 Finanzas: linear-gradient azul medianoche #0f172a → grafito #1e293b
   │  ├─ D3 Pareja: linear-gradient verde salvia #ecfdf5 → #dcfce7
   │  ├─ D4 Resiliencia: linear-gradient ámbar #fef3c7 → blanco crema #fffbeb
   │  └─ D5 Futuro: linear-gradient violeta #f0e7ff → índigo #e9d5ff
   ├─ Paleta cromática global: oro #FDD731, negro #020203, grafito #3F4247
   ├─ Márgenes: 40px vertical, 20px horizontal (breathing space premium)
   └─ Resultado: interfaz de lujo que inspira confianza y concentración

4️⃣  BARRA PROGRESO DINÁMICA (Línea del Horizonte Familiar)
   ├─ SVG ondulado animado: path animación onda sutil (0,50 → Q 250,30 → Q 250,70)
   ├─ Cometa viajero: círculo brillante recorre barra, animación 5s linear infinite
   ├─ Colisión en hitos: Q25, Q50, Q100, Q250, Q500
   ├─ Efecto colisión: pulse expansion (r: 8 → 20 → 8) en 600ms
   ├─ Onda expansiva: glow filter (feGaussianBlur stdDeviation=3) con opacity decay
   ├─ Posición: fixed top: 0, altura 80px, backdrop-filter blur(10px)
   ├─ Estética: línea fina minimalista con toque cinético futurista
   └─ Actualización: comet-travel animation sincronizada con progreso (currentQuestion/totalQuestions)

5️⃣  CURSOR MAGNÉTICO INTELIGENTE (Asistente Contextual)
   ├─ Cursor custom: div 24px círculo, border #FDD731 2px, opacity 0.8
   ├─ Tracking: mousemove listener actualiza left/top en tiempo real
   ├─ Magnetismo: detecta proximidad <80px a botones, snap al centro
   ├─ Transición magnética: 80ms cubic-bezier para movimiento fluido
   ├─ Estados:
   │  ├─ Normal: círculo simple, 24px
   │  ├─ Magnético: expande a 40px, box-shadow glow, background rgba(253, 215, 49, 0.1)
   │  └─ Contexto: posibilidad futura para mostrar icono de "dudas" post-15s
   ├─ Accesibilidad: cursor: none en body para ocultador cursor nativo
   └─ Impacto: reduce esfuerzo físico de apuntamiento, hipnotiza visualmente

6️⃣  EFECTO VIAJE EN EL TIEMPO (Persistencia Fantasma & Reversa)
   ├─ Persistencia anterior: clase .ghost muestra respuesta previa translúcida
   ├─ Styling ghost: opacity 0.4, font-style italic, border 2px dashed amber
   ├─ Botón atrás: reversa cinematográfica de transición (slideDown animation)
   ├─ Animación atrás: scale(0.97) + translateY(-60px) + blur(8px) en 300ms
   ├─ Sensación: como si rebobinaras una película, pasado se desdibuja conforme sale
   ├─ Interacción: mensaje subliminal "aquí es lo que elegiste, puedes cambiarlo"
   └─ Mecánica de retención: usuario no siente que "pierda" su respuesta anterior

  PSICOLOGÍA DE LA INTERFAZ — POR QUÉ FUNCIONA
═══════════════════════════════════════════════════════════════════════════════

**Gravedad Cero:**
  El movimiento fluido elimina fricción cognitiva. El usuario no experimenta
  "salto" visual que desorienta. Mantiene continuidad mental página a página.

**Háptica Digital:**
  Vibración = feedback nervioso subconsente. El cuerpo "siente" que algo pasó.
  Refuerza dopamina de respuesta física sin ruido. Genera ilusión de peso/gravedad.

**Diseño Premium:**
  Chronicle Display = tipografía de luxe (NYT, Vogue). Fondos adaptativos por
  dimensión = psicología del color contextual. Usuario percibe "herramienta profesional"
  que cuesta 500€, no "test online" que cuesta $5.

**Barra Progreso Dinámica:**
  Cometa viajero = movimiento genera dopamina. Colisiones = micro-recompensas.
  Usuario siente progreso SIN fatiga de "barra azul aburrida". Viaje = narrativa.

**Cursor Magnético:**
  Reduce fricción motora (no necesita precisión exacta). Genera ilusión de que
  interfaz "entiende intención" del usuario. Pequeño truquito = gran impacto en UX.

**Viaje en el Tiempo:**
  Persistencia fantasma = sensación de control. Usuario sabe que puede cambiar de
  opinión. No es "punto de no retorno" sino "proceso reflexivo". Reduce ansiedad.
